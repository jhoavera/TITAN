## Resumen
Las importaciones relativas causan fragilidad al reestructurar. Proponer usar alias definidos en bunfig.toml para mejorar mantenibilidad.

## Archivos afectados
- infraestructura/servidor/servidor-hono.ts
- infraestructura/servidor/bootstrap.ts

## Ejemplos de importaciones relativas (líneas)
- infraestructura/servidor/servidor-hono.ts:3 -> import { adaptarHandler } from './adaptadores/fastify-to-hono';
- infraestructura/servidor/servidor-hono.ts:4 -> import { middlewareAutenticacionJWTHono } from '../../nucleo/middleware/hono/middleware-autenticacion-jwt.ts';
- infraestructura/servidor/servidor-hono.ts:5 -> import { middlewareRateLimitInquilino } from '../../nucleo/middleware/hono/middleware-rate-limit-inquilino.ts';
- infraestructura/servidor/servidor-hono.ts:6 -> import { generateOpenApiYAML } from '../documentacion/generador-openapi';
- infraestructura/servidor/servidor-hono.ts:9 -> import * as glosarioCtl from './controladores/glosario-controlador';

## Cambios propuestos
- Sugerir actualizar importaciones en 'infraestructura/servidor/servidor-hono.ts' a rutas con alias (ej: '@/infraestructura/servidor/servidor-hono').
- Sugerir actualizar importaciones en 'infraestructura/servidor/bootstrap.ts' a rutas con alias (ej: '@/infraestructura/servidor/bootstrap').
