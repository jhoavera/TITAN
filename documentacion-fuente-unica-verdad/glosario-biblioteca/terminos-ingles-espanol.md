# Términos técnicos en inglés y su traducción/justificación

Esta tabla recoge los términos que se conservan en inglés por ser nombres propios, estándares o acrónimos técnicos, junto con su traducción o explicación en español técnico empresarial.

| Término en inglés | Mantener en inglés | Traducción / Explicación (español técnico empresarial) |
|---|---:|---|
| Drizzle | Sí | Nombre propio del ORM (mantener para evitar ambigüedad en dependencias). Explicación: "Drizzle ORM (mapeador de objetos relacional tipo ligero, genera tipos TypeScript)." |
| Fastify | Sí | Nombre del framework HTTP. Explicación: "Fastify (framework HTTP rápido y ligero)." |
| Zod | Sí | Biblioteca de validación. Explicación: "Zod (validador de esquemas con inferencia TypeScript)." |
| Git | Sí | Sistema de control de versiones. Explicación: "Git (control de versiones distribuido)." |
| Vitest | Sí | Herramienta de pruebas unitarias. Explicación: "Vitest (runner de pruebas con soporte TypeScript)." |
| Playwright | Sí | Herramienta de pruebas E2E. Explicación: "Playwright (automatización de navegadores para pruebas E2E)." |
| UUID, JSONB, GIN | Sí | Abreviaciones/estándares técnicos: "UUID (identificador único), JSONB (tipo JSON binario en PostgreSQL), GIN (índice para búsqueda full-text)." |
| README, CLI, API, PR, E2E | Parcialmente | Se mantendrán como acrónimos en inglés pero en la documentación se mostrarán con su traducción entre paréntesis (p.ej. CLI — Interfaz de Línea de Comandos). |

> Nota: En la documentación del proyecto se añadirá siempre la explicación inmediata en español técnico empresarial para garantizar máxima comprensibilidad.
